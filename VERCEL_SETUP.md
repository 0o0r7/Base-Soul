# Vercel Deployment Setup

## Create Vercel Token

1. **Go to Vercel Settings**:
   - Visit: https://vercel.com/account/tokens
   - Or: https://vercel.com → Your Profile → Settings → Tokens

2. **Create New Token**:
   - Click **"Create Token"**
   - Name: `base-soul-deployment` (or any name you prefer)
   - Scope: **Full Account** (or just the projects you want)
   - Expiration: Choose your preference (or never expire)
   - Click **"Generate Token"**

3. **Copy the Token**:
   - ⚠️ **Important**: Copy the token immediately - you won't see it again!
   - It will look like: `vercel_xxxxxxxxxxxxxxxxxxxxx`

## What I Can Do With Your Token

Once you provide the token, I can help you:

1. **Install Vercel CLI** (if not already installed)
2. **Login to Vercel** using the token
3. **Deploy your project** automatically
4. **Set environment variables** (NEYNAR_API_KEY, etc.)
5. **Configure domain** and settings
6. **Get your deployment URL**

## After Deployment

You'll get:
- ✅ Live URL (e.g., `base-soul.vercel.app`)
- ✅ Automatic deployments on git push
- ✅ Preview deployments for PRs
- ✅ Analytics and logs

## Security Note

- Keep your token private
- Don't commit it to git
- You can revoke it anytime from Vercel settings
- Consider using project-specific tokens for production
